private pure subroutine cheb_evaluate_complex(model, u, value, status, derivative, value_status, derivative_status)

Default evaluation reconstructs the physical value for LOG10 models. cheb_evaluate_polynomial always returns the raw series P and dP/du. UNDERFLOW is a nonfatal evaluation condition: affected nonzero components below the subnormal range become zero, while other components survive. Optional per-output statuses distinguish value and derivative underflow. Hard failures publish only quiet NaNs; the fitted model remains valid.
