alps_cache_sha256 ../../ALPS_rel_cache.f90

SHA-256 hashing used by the relativistic cache to identify construction inputs and compatible builds, and to check the integrity of stored cache entries. Hashes the supplied bytes without interpreting their numerical or text content. sha256_state supports init, repeated update calls, and finish, allowing arrays and files to be hashed in chunks without buffering the entire input. The sha256 and sha256_file helpers hash a character string or a file, respectively; completed digests contain 64 lowercase hexadecimal characters. SHA-256 operates on unsigned 32-bit words. This implementation stores each word in an int64 container so intermediate compression sums remain in range, then masks to the low 32 bits to implement arithmetic modulo 2**32 without relying on signed-integer overflow. Only intrinsic Fortran facilities are used.

alps_distribution_analyt ../../distribution_analyt.f90

This module evaluates a pre-defined function for f0. This is an alternative to the use of an f0 table or a bi-Maxwellian approximation. This function can be used to define f0 for the integration or for the analytic continuation (or both). It works in the non-relativistic case as well as the relativistic case.
