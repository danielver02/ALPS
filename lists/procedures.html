alps_continuation_error alps_io Subroutine

Report a failed Chebyshev continuation evaluation and terminate all MPI ranks. Called by eval_fit when its caller omits the optional status output and the evaluator reports a non-success status, such as an unavailable row, invalid model, or overflow/underflow while reconstructing the distribution or derivative. The diagnostic identifies the species, fitted row, kernel status code, and complex parallel coordinate u at which the evaluation failed. By default, row is a relativistic Gamma-grid index (igamma); nonrelativistic=.true. instead identifies a perpendicular-momentum row (iperp). The calling rank writes to stdout. MPI_Abort stops the entire communicator so other ranks cannot remain blocked in collectives, and a failed evaluation cannot silently enter the dispersion calculation as a zero contribution.

build_rel_cheb_rows alps_analyt Subroutine

Explicit initialization entry: invoke on rank 0 after derivative_f0 has loaded/constructed and normalized the transformed tables. The conditional initialization hook is shared by supported production and validation input. species maps packed slots to original species; degrees=poly_order(species). selected optionally restricts applicable slots, without changing packing. Rebuilding first releases this collection only. Inputs are never modified. SUCCESS means construction completed without unexpected row failures; expected empty/zero rows still have unavailable models and explicit states. Otherwise return the first unexpected kernel error, retain classifications for every row, and report each failure. Diagnostics remain in log10 space.

For like signs, correct the rounded H-small bound with its exact residual. small<=H/2 makes H-bound exact (Sterbenz); the residual's sign identifies an upward-rounded bound. Unlike a blanket ULP margin, exact boundary sums such as (H-spacing(H))+spacing(H) remain accepted. Opposite signs are safe.

Reconstruct factor*exp(logamp) without an out-of-range exp intermediate. A nonzero magnitude below the least subnormal is explicitly zero/UNDERFLOW. Near the upper limit, rounded logarithms can conservatively reject a value; no boundary value is clamped and no overflowing SCALE is ever attempted.
cheb_fit alps_analyt Subroutine

Default DIRECT fits values; LOG10 fits log10 of strictly positive samples. Only exact zeros strictly outside the positive coordinate interval are excluded. A zero coincident with a positive sample is an interior zero. No floors, physical support selection, or extrapolation cutoff is applied. SUCCESS/REDUCED apply to either representation; inspect representation. Finite data are supported. Quiet NaNs/infinities return errors; signaling NaNs can raise IEEE invalid before status return. FP modes are unchanged.
cheb_fit_direct alps_analyt Subroutine

Unweighted rectangular SVD fit on actual, possibly repeated/unsorted nodes. The default RCOND is max(number of samples,initial columns)*epsilon. A degenerate interval has center=u(1), scale=1 and is fitted as a constant. Rank loss causes a new lower-degree least-squares solve, never truncation. Input contract (also cheb_evaluate): finite data are supported; quiet NaNs and infinities are rejected by status. Signaling NaNs are not trap-safe: they may raise IEEE invalid before a status can be returned. No FP modes or exception traps are changed by this kernel.

cheb_reconstruct alps_analyt Subroutine

Exp is applied only to a small binary remainder; SCALE restores range. Derivative components combine ln(f), ln(ln(10)), and ln(|P_u|) before exponentiation, so an underflowing f can have a representable derivative. Trig routines perform argument reduction. Reject phases above 1/sqrt(eps) radians: multiplication by ln(10) then loses O(sqrt(eps)) absolute phase accuracy. This numerical reliability limit is unrelated to physical support.
