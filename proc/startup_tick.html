public subroutine startup_tick(start)

Start an optional elapsed-wall-time interval for startup_tock. Returns a local MPI_Wtime timestamp when profile_startup is enabled, or zero otherwise. MPI must be initialized when profiling is enabled. This routine performs no MPI communication or synchronization.

Arguments

Type IntentOptional Attributes Name
double precision, intent(out) :: start

Local start timestamp in seconds, or zero when profiling is disabled.
