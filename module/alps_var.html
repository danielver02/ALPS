Accumulated local startup wall times in seconds, initially zero. Repeated startup_tock calls add to the selected phase, so the normal rank-0 report sums work across species. No MPI reduction is performed.

Index Timed phase
1 Original VDF input.
2 Original-grid derivatives and density/current diagnostics.
3 Relativistic coordinate transformation and spline preparation.
4 Spline matrix construction and right-hand-side preparation.
5 LAPACK DGESV solve.
6 Spline evaluation on the transformed target grid.
7 Exponentiation, cone masking, normalization, and derivatives.
8 Read-only relativistic diagnostic output.
9 Analytic-continuation fitting, including its diagnostic output.
10 Total startup after parameter input and before dispersion calculations.
11 Cache input and strict build identity (build discovery once per execution).
12 Cache read, integrity, and numerical validation.
13 Cache write, verification, and atomic publication.
14 Total relativistic setup, including diagnostics and cache overhead, excluding fitting.

Phase 10 includes MPI distribution and harmonic/Bessel setup, but excludes MPI initialization and namelist input. It overlaps phases 1--9 and must not be added to them. Phase 14 overlaps phases 3--8 and 11--13; phase 10 also includes cache work. startup_report does not reset these accumulators.

Subroutines

public subroutine startup_tick(start)

Start an optional elapsed-wall-time interval for startup_tock. Returns a local MPI_Wtime timestamp when profile_startup is enabled, or zero otherwise. MPI must be initialized when profiling is enabled. This routine performs no MPI communication or synchronization.

Arguments

Type IntentOptional Attributes Name
double precision, intent(out) :: start

Local start timestamp in seconds, or zero when profiling is disabled.

public subroutine startup_tock(phase, start)

Add the elapsed time since startup_tick to one startup_seconds entry. Does nothing when profile_startup is disabled. The caller must supply a valid phase index and a timestamp obtained on the same MPI rank, and keep profiling enabled throughout the interval. MPI must still be initialized. No barrier or reduction is performed; overlapping intervals remain separate.

Arguments

Type IntentOptional Attributes Name
integer, intent(in) :: phase

Accumulator index in 1:14; see startup_seconds for the phase mapping.
double precision, intent(in) :: start

Local timestamp returned by startup_tick for this interval.

public subroutine startup_report()

Print the accumulated startup wall times in seconds on rank 0. Returns without output unless both profile_startup and proc0 are true. The report is independent of writeOut and describes local rank-0 elapsed time, not CPU time or the maximum across MPI ranks. Accumulators are neither reset nor reduced across ranks.

Arguments

None
